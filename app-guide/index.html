0:05 — Start with one task

Name your task, set a daily goal, and start tracking. Choose a normal timer or Pomodoro, with adjustable work and break intervals.

  • Start, pause or stop tracking
  • Choose normal time or Pomodoro
  • Set work and break intervals

0:13 — Turn intention into a plan

Describe your tasks and available time. Local AI proposes a session. Adjust the blocks, then confirm before adding them to your schedule.

  • Describe tasks and available time
  • Review and adjust the proposal
  • Confirm before blocks are added

0:21 — Protect a focus block

Total Focus protects a timed block. Pair the browser extension, choose blocked sites and exceptions, and optionally quiet system notifications.

  • Choose blocked sites and exceptions
  • Set the session duration
  • Optional notification quieting

0:29 — Understand your day

Insights shows recorded time, categories, your activity timeline, sustained focus and browsing patterns. Local analysis supplies context; you review what it means.

  • Time, categories and activity timeline
  • Sustained focus and browsing patterns
  • Review context before conclusions

0:37 — Make a useful work report

Generate a work report, review the summary, and export a PDF. Schedule weekly saves, then record decisions and a date to review them.

  • Generate and review a work report
  • Export a PDF or schedule weekly saves
  • Save decisions and review dates

0:45 — Connect when it helps

Optional Cloud adds Coach conversations, selected team summaries, and Google or Microsoft calendars. Review permissions; these features need an eligible plan.

  • Coach conversations
  • Selected team summaries
  • Google and Microsoft calendars

0:53 — Bring work into your tools

Link Jira or Linear tasks with an eligible plan. Calendar recaps need a configured connection. Notion publishing is unavailable in this release.

  • Jira and Linear task linking
  • Calendar recaps need a configured connection
  • Notion publishing: unavailable in 6.1.0

1:01 — Choose how your AI acts

Manage tasks, local calendar blocks, drafts, browser tools and preferences. Confirm changes. Connect external AI through the read-only MCP server.

  • Tasks, local calendar blocks and drafts
  • Browser tools, memory and confirmation
  • Connect a compatible AI through MCP

1:09 — Keep control of your data

Control sync, cloud AI and analytics separately. Exclude applications, choose retention, and export or erase data. External AI can receive report data you request.

  • Separate sync, cloud AI and analytics
  • Exclude apps and choose retention
  • Export or erase your data

1:17 — Focus with friends

Join private friend leagues for weekly focus points, without sharing work details. Set startup, tray, language and theme preferences, and check for updates.

  • Create or join a private group
  • Weekly points from eligible focus
  • Startup, tray, language, theme and updates

Version and demonstration notes

This is a feature overview of the actual FlowSight 6.1.0 renderer using fictional demonstration data and simulated desktop responses. Coach dialogue is an example, not a live model response. Narration is synthesized locally in English.

Cloud features and integrations require an eligible plan, consent and service configuration. Calendar connections are not configured in the captured build. Notion publishing is unavailable in this release. Automatic message replies are a future feature. Optional calendar recaps may be seen by event guests, and external AI clients can receive requested report data through MCP.

For detailed setup, current availability and plan terms, use FlowSight documentation. A 90-second overview introduces each feature area; it does not replace step-by-step setup instructions.
