Version and demonstration notes

This is a feature overview of the actual FlowSight 6.1.0 renderer using fictional demonstration data and simulated desktop responses. Coach dialogue is an example, not a live model response. Narration is synthesized locally in English.

Cloud features and integrations require an eligible plan, consent and service configuration. Calendar connections are not configured in the captured build. Notion publishing is unavailable in this release. Automatic message replies are a future feature. Optional calendar recaps may be seen by event guests, and external AI clients can receive requested report data through MCP.

For detailed setup, current availability and plan terms, use FlowSight documentation. A 90-second overview introduces each feature area; it does not replace step-by-step setup instructions.

Music: FlowSight Quiet Hours, an original chill instrumental composed locally for this guide. The English narration uses a locally generated neural synthetic voice.
