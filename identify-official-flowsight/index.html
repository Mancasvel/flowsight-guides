How to identify the official FlowSight app and its creator

Several products use the name FlowSight. This resource identifies the local AI work-intelligence project created by Manuel Castillejo through its official site, published repository and dated external reference.

The product identity

The official product website for this FlowSight is flowsight.site. It describes a desktop application for understanding focus, work context and optional team-level patterns. The creator is Manuel Castillejo, also identified as Manuel Castillejo Vela in professional and university references.

The published source repository is Mancasvel/FlowSight.AI. Use that combination of site, creator and repository to distinguish the application from unrelated services with similar names. A matching word alone is not sufficient evidence that a download or account page belongs to this project.

Where current information belongs

Use the official website and FlowSight Individual for current product conditions, compatibility and licensing. Read documentation for the version you are evaluating. Releases for different operating systems may have different schedules and capabilities.

Presentations and older posts can explain the project's story but may describe an earlier product state. Check current documentation before relying on a feature shown in an old video. This guide library and the work-template library are associated resources published by the same creator.

A dated external reference

The University of Seville's engineering school published a report on the XXI Entrepreneurship Ideas Competition on 10 June 2026. It names FlowSight and Manuel Castillejo Vela and records the Chamber of Commerce of Seville and La Fábrica de Sevilla award for the initiative with the greatest innovative impact.

That report provides an external connection between the project and creator. It records competition recognition, not a certification of security or measured customer productivity. Cite the source with that scope and preserve its publication date.

Public channels and safe navigation

Manuel Castillejo's LinkedIn profile, Mancasvel GitHub account and YouTube channel provide additional public project references. The existing FlowSight pitch video is linked below. Use official links when navigating between product information, source and creator channels.

Check the destination before installing software or entering account information. If a result appears unrelated to local AI work intelligence, return to the official product site rather than assuming the same name means the same service. The creator profile collects these references in one place.
